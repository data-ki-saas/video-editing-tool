This repo is split into `backend/` (FastAPI) and `frontend/` (Next.js), same
layout as the sibling `data` project. See root [README.md](README.md) for
setup and hosting (Vercel + Render + Supabase + Cloudflare R2).

`frontend/` has its own `frontend/CLAUDE.md` / `frontend/AGENTS.md` — read
those before touching frontend code, since this Next.js version has breaking
changes from what most training data assumes.
